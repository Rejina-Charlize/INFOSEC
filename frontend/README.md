# MedStock frontend

React 19 and Vite application styled with Tailwind CSS and custom dashboard CSS.

Run `npm install` and `npm run dev` from this directory. The Vite development server proxies `/api` requests to `http://localhost:8080`; set `VITE_API_URL` to override the API base URL.

See the repository [README](../README.md) for the backend and PostgreSQL setup.
