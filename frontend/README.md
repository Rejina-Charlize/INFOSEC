# MedStock frontend

React 19 and Vite application styled with Tailwind CSS and custom dashboard CSS. The Node/Express API and MongoDB provide inventory data.

From the project root, run `npm install` and `npm run dev:web`. The Vite development server proxies `/api` requests to `http://localhost:8080`; set `VITE_API_URL` to override the API base URL.

See the repository [README](../README.md) for the Express API and MongoDB setup.
